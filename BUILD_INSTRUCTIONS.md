# Build Instructions

## Prerequisites

1. **Flutter SDK**
   - Version: ^3.22.2 or higher
   - Download from: https://flutter.dev

2. **Dart SDK**
   - Version: ^3.2.0 or higher
   - Included with Flutter

3. **Windows Build Tools**
   - Visual Studio 2022 with C++ build tools
   - Windows 10/11 SDK

## Build Steps

### 1. Setup Flutter

```bash
# Verify Flutter installation
flutter doctor

# Ensure Windows support is enabled
